## [0.1.0] - 2026-10-13

### Added

- `trace-driven-debugging` skill: when to collect runtime evidence, starting runlens, reproducing the request, the read-hypothesize-fix-verify loop over the six runlens MCP tools, and reporting before and after numbers.
- References: per-agent MCP setup for Claude Code, Codex CLI, Gemini CLI and Cursor, the OTLP fallback, N+1 fixes for raw SQL, Prisma, Drizzle, TypeORM, SQLAlchemy and Django, and recipes for outbound calls, slow queries, error triage and chatty services.
- Claude Code plugin manifest and single-plugin marketplace.
- `node:test` validator for frontmatter, manifests, links, anchors and tool names, run in CI.
